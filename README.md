# Internship Radar

A personal Summer 2027 internship feed focused on **enterprise / corporate technology roles** rather than generic SWE recruiting.

The radar pulls public internship feeds, filters them against a configurable set of target role families, ranks Dallas–Fort Worth / Texas and remote roles higher, and writes the latest matches to `data/matches.json` plus `LATEST.md`.

## What this repo targets

Primary role families:

- Corporate IT / Information Technology
- Technology Analyst / IT Analyst
- Business Systems / Systems Analyst
- Application Analyst / Application Support
- IT Quality Assurance / Software QA / Testing
- Technology Operations
- IT Audit / Technology Risk / IT Controls
- Technology Consulting / Advisory
- Product Analyst / Technical Product / Product Management internships

It intentionally **deprioritizes pure SWE, quant, embedded/hardware, research-heavy ML, and cybersecurity-specialist roles** unless they also match one of the target role families.

## Location priority

1. Dallas–Fort Worth / North Texas
2. Texas
3. Remote U.S.
4. Other U.S. relocation opportunities

## Sources

The default config currently checks machine-readable public feeds from:

- ApplyGuy's 2027 internships repository
- SimplifyJobs / Pitt CSC Summer 2027 internships repository

You can add more JSON feeds in `config.json` later without rewriting the filtering logic.

## Files

- `radar.py` — fetches, normalizes, filters, scores, and writes matches
- `config.json` — target keywords, exclusions, locations, source URLs, and scoring
- `data/known_applied.json` — optional company/role entries to suppress from the output
- `data/matches.json` — machine-readable filtered results generated by the workflow
- `LATEST.md` — human-readable current feed generated by the workflow
- `.github/workflows/update-radar.yml` — automatic scheduled refresh

## Run locally

```bash
python radar.py
```

The script only uses Python's standard library, so there are no packages to install.

## Mark roles as already applied

Add entries to `data/known_applied.json`:

```json
[
  {"company": "Fisher Investments", "role": "Information Technology Internship"},
  {"company": "RSM", "role": "Managed IT Services Service Desk Consulting Intern"}
]
```

The matcher will suppress close company/title matches from the generated feed.

## Customize your search

Edit `config.json` to add or remove:

- role keywords
- hard exclusions
- location preferences
- graduation/season keywords
- source feed URLs

The repository is deliberately simple so you can tune it as your internship search changes.

## Automation

GitHub Actions runs the radar on a schedule and commits refreshed `LATEST.md` and `data/matches.json` when results change. You can also run the workflow manually from the **Actions** tab.

> Listings can change or close at any time. Always verify the employer's official posting before applying.
